# RVACoin Releases

This repository provides official, publicly downloadable releases of RVACoin software.

Releases include RVACoin Core executables for supported desktop platforms and signed Android packages for RVACoin Mobile. Download the latest version from the [Releases](https://github.com/RVACoin-io/rvacoin-release/releases) page.

## Available software

- **RVACoin Core:** Qt wallet, daemon, CLI, and transaction utility.
- **RVACoin Mobile:** Android wallet distributed as `rvacoin-mobile.apk`.

For project information and support, visit [rvacoin.io](https://rvacoin.io) or contact [support@rvacoin.io](mailto:support@rvacoin.io).

## Verify downloads

Before installing or running a download, compare its SHA-256 checksum with the checksum published in the corresponding release notes.

Only download RVACoin releases from this repository or links published on the official RVACoin website.
