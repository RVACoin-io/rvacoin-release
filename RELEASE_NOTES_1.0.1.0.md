# RVACoin Core 1.0.1.0

RVACoin Core 1.0.1.0 is the initial public Windows desktop release distributed through the official RVACoin release repository.

## Included

- RVACoin Qt desktop wallet for 64-bit Windows.
- RVA Namespace access controlled by the wallet's designated authorization address.
- The RVA Namespace authorization address is shown prominently in the receiving-address list.
- Namespace addresses can be copied from the **My Namespaces** context menu.
- Authorization addresses retain the wallet's configured receiving-address type.
